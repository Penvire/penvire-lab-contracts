Try the model locally

  1. Save all three files above in the same directory.
  2. Run devenv up in the backend checkout.
  3. From the download directory, import the sample store with the OpenFGA CLI: 
    fga store import --api-url http://127.0.0.1:8090 --file platform.fga.yaml
  4. Open the local Playground and select Platform account administration.
  5. Check account_read on platform:global. Expect Allow for user:reader and Deny for client:alice.

To run the full suite without starting a server, run fga model test --tests platform.fga.yaml.
